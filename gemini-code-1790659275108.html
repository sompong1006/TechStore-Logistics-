สรุปทฤษฎี Discrete Mathematics & Source Code

1. ทฤษฎีกราฟ (Graph Theory Specification)

  • Vertex (จุดยอด 6 จุด): แทนศูนย์กระจายสินค้าและสาขา ได้แก่ Central Hub, Lat Phrao, Siam, Bangna, Rangsit, Rama 2
  • Edge (เส้นเชื่อม 8 เส้น): แทนเส้นทางขนส่งระหว่างสาขา พร้อมค่าน้ำหนัก (Weight = ระยะทาง km)
  • Path (เส้นทาง): เส้นทางลำดับการจัดส่ง เช่น Central Hub → Siam → Rama 2

2. โครงสร้างต้นไม้ (Tree Theory Specification)

  • Root: All Products (ระดับ 0)
  • Parent Nodes: Hardware, Accessories, Software (ระดับ 1)
  • Child / Leaf Nodes: Laptop, GPU, Mouse, Keyboard, OS, Office (ระดับ 2)
  • ความสูงของ Tree: 3 ระดับ (Levels 0, 1, 2)
